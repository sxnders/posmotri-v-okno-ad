# Посмотри в окно

Приложение, которое показывает видео из окон разных городов. Проект выполнен как стилизация готового модуля: HTML и скрипт уже работали, нужно было написать CSS по макету.

## Что внутри

- лейаут на Flexbox, элементы подогнаны под макет;
- кастомные чекбоксы через псевдоэлементы и `:checked`;
- состояния `:hover`, `:active`, `:focus-visible` у кнопок, чекбоксов, поля и карточек;
- видео и превью подогнаны через `object-fit`;
- обрезка длинных названий и описаний (`text-overflow`, `line-clamp`);
- позиционирование прелоадеров и сообщений об ошибках;
- кастомный скроллбар списка карточек.

## Структура

- `index.html` — разметка и шаблоны `<template>`;
- `styles/style.css` — основные стили;
- `styles/preloader.css`, `styles/error.css` — прелоадер и ошибка;
- `fonts/` — шрифты Oswald и Fira Sans Condensed;
- `scripts/script.js` — логика приложения.
